# 🏬 Online Stall Booking System

This project is a **full-stack web application** designed to simplify the process of booking stalls for events, exhibitions, and trade fairs. It allows users to seamlessly view available stalls, register, and book their preferred slots, while providing the admin with tools to manage users, stalls, and bookings efficiently.

## 🔧 Tech Stack

- Frontend: React.js, CSS
- Backend: Java, Spring Boot (optional if used)
- Database: MySQL (or any other you configured)
- Build Tool: Vite
- Version Control: Git & GitHub

## 🚀 Features

### 👥 User Side
- User Registration & Login
- View available stalls with real-time updates
- Book a stall based on location or availability
- Responsive UI for mobile and desktop

### 🔐 Admin Side
- Admin Login
- Add / Edit / Delete stalls
- Manage user bookings
- Dashboard for monitoring stall status
